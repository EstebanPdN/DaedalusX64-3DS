# Credits and provenance

This fork starts from MasterFeizz/DaedalusX64-3DS commit `31c5e560d4cbd11d6e5b50e5e42c25b9598a68a9`. Its Git history and existing source copyright notices are preserved.

- **MasterFeizz:** Nintendo 3DS port, CTR integration, ARM work and platform libraries.
- **StrmnNrmn and the Daedalus/DaedalusX64 contributors:** original emulator and its continuing development.
- **cmf028:** major contributions to the ARM dynamic recompiler.
- **Rinnegatamante and xerpi:** PS Vita port, an important ancestor of the CTR work.
- **TheFloW:** dynamic recompiler contributions.
- **kreationz, salvy6735, Corn and Chilly Willy:** original DaedalusX64 work.
- **Wally, z2442, mrneo240 and TheMrIron2:** optimizations, build work, ports and project maintenance.
- **Azimer:** audio plugin work from which parts of this emulator's audio are derived.
- **MrHuu:** inherited icon and banner artwork.
- **devkitPro contributors:** devkitARM, libctru, citro3d and 3DS build tools.
- **MasterFeizz/picaGL and imgui-picagl, Omar Cornut and Dear ImGui contributors:** graphics/UI dependencies.
- **zlib and libpng contributors:** compression and PNG support.
- **3DSGuy/jakcron and Project_CTR contributors:** makerom and ctrtool packaging/inspection tools.
- **EstebanPdN:** maintenance of this fork, stability changes, tests and build documentation added in 2026.

This list supplements rather than replaces copyright notices in the source and bundled data. Dependencies are identified in `scripts/dependencies.json`; their own license files remain in the fetched sources. New fork-owned source is marked GPL-2.0-or-later. Original files retain their existing terms; this document does not relicense third-party code or artwork.

Reference projects studied during planning include DaedalusX64/daedalus, Gopher64, Project64, Mupen64Plus, ares, parallel-rdp/parallel-rsp and 3DS ports of Super Mario 64 and Mario Kart 64. Studying a reference is not a claim that its code was imported. No code from those alternative emulators or game ports is imported by the initial stability patch.
